# ⚜ زاهر سالمان للسجاد — ZAHER SALMAN CARPETS ⚜

منصة ويب وتجربة تفاعلية فاخرة لدار **زاهر سالمان للسجاد** (تراث متوارث منذ عام 1928) متخصصة في اقتناء وتفصيل سجاد الحرير الطبيعي الصافي 100% المعقود يدويًا للقصور والفلل الفاخرة.

---

## 🌟 مميزات المنصة:
- 👑 **Hero Scroll Sequence**: حركة ديناميكية غامرة لغزل خيوط الحرير وتمايل السجاد مع التمرير.
- 🧵 **Craftsmanship Explainer**: استعراض مراحل الصنعة اليدوية الأربع (الشرنقة، النول العتيق، عقدة الحرير، الإرث الملكي).
- 📜 **The Loom Chronicles**: مسار أفقي تفاعلي (Horizontal Pinned Rail) يستعرض أسرار النول والحرير.
- 🏺 **Masterpiece Portfolio & Royal Lightbox**: كتالوج السجاد الملكي مع إمكانية استعراض صور وزوايا متعددة لكل سجادة بدقة فائقة.
- ⭐ **VIP Patronage Testimonials**: آراء وتقييمات حصرية لمقتنين من صفوة المجتمع والقصور.
- 💬 **Direct WhatsApp Concierge**: ربط فوري لطلب الاستشارات وتفصيل السجاد عبر الواتساب على الرقم `+201044104429`.
- 🛠️ **Royal Admin Dashboard**: لوحة تحكم كاملة لإدارة كتالوج السجاد، رفع صور متعددة لكل قطعة، إدارة تقييمات العملاء، واستقبال وتصدير طلبات الاستشارة.
- 🌐 **Bilingual System**: دعم كامل للغتين العربية (RTL) والإنجليزية (LTR).
